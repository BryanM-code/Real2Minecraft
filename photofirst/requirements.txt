# The photo-first pipeline's extra packages, on top of r2m_train (training/requirements.txt).
# MoGe and its geometry helper go in without their dependency lists: MoGe's own list pulls in
# gradio and other demo packages. From the repository root:
#
#   r2m_train\Scripts\python -m pip install --no-deps "git+https://github.com/microsoft/MoGe.git@74fbce054ebed49800de42d0ad0e83495065719a" "utils3d_moge @ git+https://github.com/EasternJournalist/utils3d-moge.git@62f09d58509485564e24d5d9f6aac9ee9ebc0c37"
#   r2m_train\Scripts\python -m pip install -r photofirst/requirements.txt
#
# MoGe-3 (front.MODELS[3], `--moge 3`) also needs FlexGEMM, which runs on Triton: on Windows
# the community build triton-windows, 3.6 for torch 2.11 (2.10/2.11 -> 3.6). FlexGEMM's CUDA
# extension is opt-in (FLEX_GEMM_BUILD_CUDA=1); without it the install is pure Triton and needs
# no compiler. At the commit MoGe pins:
#
#   git clone https://github.com/JeffreyXiang/FlexGEMM.git && cd FlexGEMM
#   git checkout b2fadb29d41846c7981ade6801ffc689fae119cf
#   ..\r2m_train\Scripts\python -m pip install . --no-build-isolation --no-deps
#
# Several photos (front_mv): MapAnything, Apache 2.0, into r2m_train at the commit tested:
#
#   r2m_train\Scripts\python -m pip install "git+https://github.com/facebookresearch/map-anything.git@3d10cf7a3016fc0f9bb13a071ee66c47b10be0d9"
#
# Depth Anything 3 (front_da3) needs numpy < 2, so it has its own venv, r2m_da3 (Python 3.10,
# untracked like the others): torch 2.11 + cu128, numpy 1.26.4, then the package without its
# dependency list (it pins gradio, xformers and others the arrays do not need) and what its
# imports do need:
#
#   py -3.10 -m venv r2m_da3
#   r2m_da3\Scripts\python -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
#   r2m_da3\Scripts\python -m pip install numpy==1.26.4 "git+https://github.com/ByteDance-Seed/Depth-Anything-3.git@3d835ec1a5802d64a8b8b15f817a1ab54809bfe4" --no-deps
#   r2m_da3\Scripts\python -m pip install moviepy==1.0.3 addict==2.4.0 matplotlib==3.10.9 pycolmap==4.2.1 evo==1.38.0 omegaconf einops safetensors huggingface_hub==2.2.0 opencv-python-headless==4.11.0.86 pillow scipy trimesh
#
# Weights download into the Hugging Face cache on first use and never go in this repository:
# Ruicheng/moge-2-vitl-normal (model.pt, 1.32 GB), Ruicheng/moge-3-vitl (model.pt, 1.38 GB),
# facebook/map-anything-apache, depth-anything/DA3-LARGE-1.1 (model.safetensors, 1.57 GB;
# its model card says Apache 2.0, the DA3 repository's table CC BY-NC 4.0: check before any
# use beyond local research). photofirst.looks uses the DINOv2 weights already in the torch
# hub cache (dinov2_vitl14_reg4_pretrain.pth).
